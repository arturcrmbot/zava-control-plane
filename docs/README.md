## Doc taxonomy

Docs fall into five buckets. Each topic has **one canonical home**;
everything else points at it.

### 1. Source documents (immutable inputs)

Never edited. Referenced as authoritative ground truth.

| File | Purpose |
|---|---|
| [poc1-brief.md](poc1-brief.md) | The WPP POC1 brief, verbatim. The 13 acceptance criteria live here. |
