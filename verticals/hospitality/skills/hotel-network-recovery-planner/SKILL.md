# Hotel network recovery planner

Rank recovery options by protected-arrival coverage, guest disruption, travel
time and recovery spend. Cross-property relocation always requires named human
approval. Restoration, relocation and shift moves must reference real work
order, room, booking and shift IDs from the evidence. Produce a recommendation,
never a mutation.
