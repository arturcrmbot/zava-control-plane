# Solene — distinctiveness benchmark

## Category competitive set

Solene competes in sustainable luxury fragrance against:

- **Le Labo** — minimalist apothecary aesthetic, hand-labelled bottles
- **Diptyque** — heritage Parisian, oval label, illustrated motifs
- **Maison Margiela Replica** — memory-trigger campaign concept
- **Aesop** — austere amber bottles, technical product copy

## Where Solene must remain distinct

| Code | Solene owns | Avoid (read as competitor) |
|---|---|---|
| Surface | Pewter / smoke matte | Glossy black (Margiela) |
| Bottle | Opaque ivory glass | Clear amber (Aesop / Le Labo) |
| Type | Apoc Revelations + GT Sectra | Typewriter mono (Le Labo) |
| Composition | Botanical close-up, no humans | Memory-trigger lifestyle (Margiela) |
| Provenance | Soil-to-stopper, regenerative | Apothecary craft (Aesop / Le Labo) |
| Tagline format | Two words | Long-form product names (Le Labo) |

## Distinctiveness scoring rubric

When `brand-guardian` scores a concept, distinctiveness is high when:

- ≥3 of Solene's owned codes are present in the still / storyboard.
- ≤1 code from the avoid column is visible.
- The botanical / soil motif is the protagonist (not the wearer / not
  the bottle).

Distinctiveness is **low** when:

- The composition could swap the Solene wordmark for a competitor's
  wordmark and still read coherently.
- The grade or palette mimics one of the four competitors directly.
- Typography uses typewriter mono or apothecary script.
