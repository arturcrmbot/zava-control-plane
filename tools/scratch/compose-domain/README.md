# compose-domain sandbox

Generated artefacts from `docs/superpowers/skills/compose-domain` go here,
one subdirectory per invocation:

```
tools/scratch/compose-domain/<YYYYMMDD-HHMMSS>-<domain-name>/
```

Everything in this directory is gitignored. The skill never writes
anywhere else. Graduation into the real trees is a separate manual step
documented in each run's `GRADUATION.md`.

To clear all sandbox runs:

```bash
rm -rf tools/scratch/compose-domain/*
```
